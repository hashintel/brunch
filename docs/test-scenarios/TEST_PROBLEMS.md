## pplx generated problems

### Easy

1. Personal habit tracker  
Build a simple app for one user to track daily habits like reading, exercise, and sleep. It should support streaks, reminders, and a weekly summary, and it should work well on mobile.

2. Bookmark organizer  
Create a small app where users can save links, tag them, search them, and mark favorites. It should feel faster and cleaner than a browser bookmark manager and support importing existing bookmarks.

3. Team lunch picker  
Make a lightweight web app for a small office team to suggest lunch options, vote on them, and pick a winner for the day. It should avoid showing the same places too often and let an admin manage the restaurant list.

4. Markdown notes CLI  
Build a CLI tool that manages local markdown notes with commands for creating, tagging, searching, and linking notes together. It should be fast, scriptable, and work well in terminal-heavy workflows.

### Medium

5. Shared calendar for a club  
Create a calendar app for a small community group to manage events, RSVPs, recurring meetings, and announcements. Organizers should be able to edit events, and members should get reminders and see schedule changes clearly.

6. Lightweight invoicing system  
Build a small invoicing tool for freelancers that can create invoices, track payment status, calculate taxes, and export PDFs. It should support multiple currencies and basic client management.

7. Home inventory tracker  
Design an app for tracking household items, their location, purchase date, warranty details, and estimated value. Users should be able to search quickly, attach photos, and get reminders before warranties expire.

8. Package health dashboard  
Create a dashboard for a software team that tracks internal packages or services and shows version drift, stale dependencies, missing documentation, and recent release activity. It should work across several repositories and make problem areas obvious.

### Hard

9. Resource booking system  
Build a web app for booking shared resources like meeting rooms, desks, studio equipment, or parking spaces. It must prevent conflicting reservations, support recurring bookings, handle exceptions, and provide an admin view for policies and overrides.

10. Document intake and review pipeline  
Design a system that accepts PDFs and text documents, extracts metadata, stores originals, supports full-text and semantic search, and routes uncertain extractions for human review. It should be affordable for a small organization and preserve an audit trail.

11. Internal workflow builder  
Create a tool for non-technical staff to define simple approval workflows such as expense approval, leave requests, or procurement review. It should allow branching rules, notifications, manual overrides, and a history of who did what.

12. Multi-tenant feature flag service  
Build a lightweight feature flag platform for small engineering teams that supports environments, percentage rollouts, targeting rules, audit logs, and SDK access for web services. It should be simpler than enterprise tools but still safe enough for production use.
