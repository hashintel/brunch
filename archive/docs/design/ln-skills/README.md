# ln-skills Design Notes

This directory holds design rationale for Brunch's `ln-*` agent-skill workflow and related dev-layer self-tooling.

These documents are not executable skills. Runtime skill instructions live under `.agents/skills/ln-*/`; accepted operational protocols belong in `AGENTS.md` or `docs/praxis/`; canonical product truth remains in `memory/SPEC.md` and `memory/PLAN.md`.

| Document | Role |
| --- | --- |
| `EVOLUTION.md` | Dev-layer trajectory for the `ln-*` skill family, `memory/` ontology, proposed file-backed spec registry, and possible dev/product ontology convergence. Not product SPEC. |
