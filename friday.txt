------------------------------------------------------

(auto-save, session list, model selection). CreateSpec needs to:

- Accept a projectId from Home's session list
- Persist all wizard state (questions, assumptions, requirements, spec)
  back to the shared session format
- Add auto-save (reuse useAutoSave pattern from Home)

Files to touch:
  - CreateSpec/index.tsx (add session loading)
  - CreateSpec/hooks/useSpecWizard.ts (integrate session save/load)
  - Home hooks: useSession (ensure API compatibility)

Definition of done:
  - Can navigate from Home project list → CreateSpec with project loaded
  - CreateSpec auto-saves to same backend as Home
  - Returning to Home shows updated project data
