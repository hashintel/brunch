## resume orientation on non-empty spec

![`/consult` menu on resumed spec](<CleanShot 2026-07-09 at 17.03.34@2x.png>)

the `/consult` menu:

- it shouldn't say ` [ Consult ] ` in the upper right border it should say ` [ Specify ] ` and we should retain the name of the spec in the lower right
- should probably not use a fixed-height and scroll-bar: the scroll-bar is hard to detect unless you know it's there, and so it's hard to understand that there are more options than the 4 visible ones 
	- although: that being said, in "specify" mode those first four options might be all we really need
- "Continue" has clearly become semantically confused: the subtext describes what it does ("Stay inert until your next instruction."), but 
	- it shouldn't be the very first option
	- it certainly shouldn't be described as "Continue" -- it's rather more like the "Other" option in the `ask` component, in the sense that if I choose it I will enter an inert state where I as the user can use the Editor to say what I want to do
	- ...and therefore it shouldn't be the first option in the list
